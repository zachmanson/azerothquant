# Addon and Brain talk only through files, via a SavedVariables round-trip

WoW addons have no network or file access, so the Addon exports everything it collects through SavedVariables (written on `/reload` or logout) and imports Recommendations from a Brain-generated Lua file in its own folder (read on `/reload` or login). A watcher on the PC runs the Brain whenever the SavedVariables file changes, with a manual CLI command as a fallback. The Brain never writes to SavedVariables, since the client overwrites that file on every logout. We chose an offline Brain over an all-in-addon design (like WOW4E_AH_Trader) because SavedVariables is a poor database: the whole file is rewritten on every reload and makes loading slower as it grows, which forces in-addon tools to cap history and throw away individual Listings.
